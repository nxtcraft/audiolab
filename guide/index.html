How AudioLab Works

AudioLab uses FFmpeg.wasm — the industry-standard FFmpeg audio/video tool compiled to WebAssembly — running entirely inside your browser tab. This means:

  • Your files never leave your device. There is no server involved after the initial page load.
  • No size limits imposed by a server. File size is limited only by your device's RAM.
  • Works offline once FFmpeg.wasm is cached by your browser (Service Worker).

On first load, the browser downloads ~25 MB of WebAssembly. This takes 5–15 seconds on a typical connection and is cached for future visits.

MP3 Cutter — Step by Step

The MP3 Cutter lets you trim any section from an audio file — to cut a song intro, remove silence, or extract a specific segment.

✂️
MP3 Cutter
Trim audio to any start and end time
  1. Go to AudioLab and wait for FFmpeg to finish loading (progress bar in the loading screen).
  2. Click the MP3 Cutter tab.
  3. Drag and drop your audio file onto the upload zone, or click Browse Files. Supported: MP3, WAV, OGG, AAC, FLAC, M4A, OPUS.
  4. The audio player appears. Press play to find your desired start point. Click Set Start at the right moment, or type the time manually in mm:ss format.
  5. Find your desired end point. Click Set End or type the time manually.
  6. Select your output format (MP3 is recommended for universal compatibility).
  7. Click Cut Audio. Processing takes a few seconds.
  8. When the Download button appears, save your trimmed file.
Tip: For ringtones, aim for 20–30 seconds. For notification tones, 1–3 seconds. The cutter works with sub-second precision — you can enter times like 1:23.5 for millisecond-level accuracy.

Ringtone Maker

The Ringtone Maker is a specialised version of the cutter optimised for phone ringtone creation. Use it to:

  • Create ringtones (20–30 seconds, MP3)
  • Create notification tones (1–3 seconds)
  • Create alarm sounds (any length)
Android: Download the MP3, place it in the Ringtones/ folder on your phone's internal storage, then select it in Settings → Sound → Phone Ringtone.

iPhone: Convert the MP3 to M4R (use the Audio Converter tab: format = AAC, rename the .aac extension to .m4r), then import it via iTunes or Finder on a Mac.

Volume Booster

Increase or decrease the volume of any audio file. The booster uses FFmpeg's volume filter with decibel (dB) control:

dB ChangePerceived EffectTypical Use
+6 dB~2× louderQuiet recordings, lecture audio
+10 dB~3× louderVery quiet files, old recordings
+20 dB~10× louderExtremely quiet files (risk of clipping)
-6 dB~50% quieterOverly loud music, reduce before mixing
Clipping warning: Boosting volume above the peak level causes distortion (clipping). If your output sounds crackling, reduce the dB boost and try again. Use +6 dB increments and listen after each step.

Audio Merger

Combine multiple audio files into one. The merger concatenates them in the order you arrange them. Use it to:

  • Join split podcast episodes back into one file
  • Create a continuous mix from multiple songs
  • Combine voice recordings made in separate sessions
  1. Click the Audio Merger tab.
  2. Upload your first audio file.
  3. Click Add More Files to upload additional files. You can add as many as you need.
  4. Drag the files to reorder them (the merge plays them top to bottom).
  5. Select the output format and click Merge Audio.
Format tip: For best results, convert all input files to the same format and bitrate before merging. Mixed bitrates are handled automatically but may cause quality inconsistencies at join points.

Frequently Asked Questions

Is AudioLab really free?
Yes, AudioLab is completely free — no sign-up, no watermarks, no file limits, no ads injected into your audio. All processing runs in your browser using FFmpeg.wasm.
Does my audio file get uploaded to any server?
No. AudioLab uses FFmpeg.wasm which runs entirely in your browser. Your audio files are never uploaded or sent to any server — they stay on your device throughout the entire process.
Why does AudioLab take a few seconds to load?
AudioLab loads FFmpeg.wasm — a ~25 MB WebAssembly binary — the first time you visit. This is a one-time download per session. Subsequent tool actions run instantly since FFmpeg is already loaded in memory. The binary is also cached by the Service Worker for offline use.
What is the maximum file size AudioLab can handle?
File size is limited by your device's RAM, not a server limit. Practically, most devices handle files up to 500 MB easily. For very large files (>200 MB), close other browser tabs to free memory.
Can I make a ringtone with AudioLab?
Yes. Use the Ringtone Maker tab. Upload any song, set the start and end time for the section you want (typically 20–30 seconds), select MP3 output, and download. For iPhone ringtones, convert to AAC format and rename the file extension from .aac to .m4r.
Can I cut FLAC or M4A files?
Yes. AudioLab accepts FLAC, M4A, OPUS, WAV, OGG, and AAC as input — not just MP3. The "MP3 Cutter" name refers to the common use case; the tool actually handles all major audio formats.
